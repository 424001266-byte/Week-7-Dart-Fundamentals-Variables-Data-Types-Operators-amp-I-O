**Scenario**

This program is a Student Grade Report that demonstrates Dart variables, data types, arithmetic operators, comparison operators, and console input/output. It calculates a student's final score based on the average score and completed activities.

**Data Types Used**
String – stores the student's name.
int – stores the number of completed activities.
double – stores the average score and calculated values.
bool – stores enrollment and comparison results.
Operators Used

**Arithmetic Operators**
+ – adds the average score and activity bonus.
* – calculates the activity bonus.
- – calculates the remaining activities.
~/ – performs integer division.
% – calculates the remainder.

**Comparison Operators**
>= – checks if the student passed and achieved an excellent score.
!= – checks that the final score is not zero.


**How to Run**

Open the terminal in the project folder and run:

dart run

To format the code, run:

dart format .


**Expected Output**

The program displays the student's name, completed activities, average score, activity bonus, final score, and the results of the comparison operations.
